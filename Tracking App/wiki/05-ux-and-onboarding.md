# UX & Onboarding Framework

## Design & UI Principles
1. **Low Cognitive Load:** Clear visual distinction between workspaces via customizable icons, badges, and accent color themes.
2. **Context Switching Efficiency:** A Discord-style left sidebar allowing instant navigation between workspaces, with a persistent top navigation bar for "Unified Views" (Master Calendar, My Tasks, Master Ledger).
3. **Mobile-First Responsiveness:** Immediate fast loading for quick on-the-go chat, calendar checks, or transaction entry.

---

## User Onboarding Flow

1. **Step 1: Sign Up / Account Creation**
2. **Step 2: Workspace Setup Prompt**
   * *Option A:* Create First Workspace
   * *Option B:* Join via Invite Link / QR Code
3. **Step 3: Interactive Module Tour**
4. **Step 4: Group Invite Prompt**

---

## In-App Upgrade & Conversion Triggers

Strategic contextual prompts that encourage users to upgrade without blocking core utility:

1. **Transaction Threshold Prompt:** When a workspace reaches 25 transactions in a month (nearing the 30 free limit), display a banner: *"Upgrade to Pro for unlimited expense tracking and visual analytics."*
2. **Privacy Masking Toggle:** When a user toggles "Mask Event Details" on their Unified Calendar, trigger a Pro feature unlock prompt.
3. **Member Capacity Alert:** When an admin attempts to invite an 11th member to a workspace, present the **Pro Workspace Pass** upgrade option ($11.99/mo for unlimited members).
4. **Data Export Request:** Clicking "Export Workspace Ledger to CSV" prompts a workspace upgrade.
